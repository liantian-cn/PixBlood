# 第三版实施验收记录

## 已完成

- uv 更新锁文件并同步环境；直接声明 PySide6、numpy、opencv-python、xxhash、psutil，
  pyright 位于 dev 依赖组。移除 pillow、pywin32，未请求无关依赖升级。
- `uv run pyright pix`：0 errors、0 warnings；`uv run python -m compileall pix` 通过；
  `git diff --check` 通过。
- 真实桌面的一次性诊断成功定位 `(0, 0, 268, 12)`；局部 GDI 截图通过两角标记、
  Matrix 检测格验证，全部 62 个 Context 属性读取成功。未向游戏发送按键。
- 合成图像验证精确标记、单像素偏差拒绝、多区域拒绝及负原点坐标换算。
  验证 Cell、ValueBar、IconTile 的区域、不可写快照、图标 hash，符文 0–6、
  能量 0/125、充能 0/1/2、白骨层数 0/5/9/12，以及两套曲线节点和区间中点。
- 以旧鲜血 TOML 为独立参照，3000 组固定随机种子的状态覆盖全部 29 条规则，
  返回宏名一致。包含生命 55、能量 42/100、白骨时间 5、层数 5/9、目标生命 20
  附近的状态。12 个宏名、键位及宏文本与旧宏和第三版约定逐项一致。
- 键盘发送使用模拟消息接口验证：主键解析、减号主键、重复修饰键拒绝、
  扫描码与扩展位、释放位、逆序释放和中途发送失败后的释放尝试。
- 实际 Qt 线程验证：截图及循环启动、运行时 FPS 更新、停止再启动创建新 Rotation、
  PID 更新保留 Rotation、1.25 秒 Sleep 不受 PID/FPS 更新影响、Sleep 可停止、
  先停 Action 再停 Capture、关闭时丢弃尚未返回的慢动作。验证时替换键盘发送，
  没有真实按键消息。
- 本地执行验证：新鲜帧复用、过期错误抑制与恢复、动作前再次检查帧龄和当前失败状态、
  Sleep 时长限幅、Rotation 构造失败、Capture 定位失败重试与恢复、失败清空图像。
- 离屏 UI 验证固定 1600×1200 尺寸、四区域布局、默认频率、连续同文日志去重、
  首次时间戳保留、2000 条上限。离屏 Qt 不自动加载系统字体，截图验证时单独加载
  Windows 字体；应用本身仍使用默认字体和样式。

这些检查通过临时命令执行，未新增测试框架或普通功能测试文件。
`pix/test_captura.py` 是计划指定的独立诊断入口。
